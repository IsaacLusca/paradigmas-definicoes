## 1. Contexto / Motivação

Prolog não tem laços `for`/`while` como linguagens imperativas. Como escrever algoritmos que
repetem? A resposta é a **recursão** — e em Prolog ela é ainda mais natural, porque a
própria unificação e o backtracking conduzem a recursão. Nesta aula você vê como definir
predicados recursivos, a diferença entre recursão **comum** e **de cauda**, e como usar
**estruturas de dados** (termos compostos) para modelar informações.

---

## 2. Predicados recursivos

Um predicado é definido **recursivamente** se uma ou mais regras de sua definição se
referem **ao próprio predicado**. Toda definição recursiva tem **duas partes**:

1. **Cláusulas-base** — fatos ou generalizações (encerram a recursão).
2. **Regras recursivas** — chamam o próprio predicado (reduzem o problema).

O tratamento das regras recursivas se dá **naturalmente pelo backtracking**.

```prolog
fact(N, F) :-
    N > 0,
    succ(NewN, N),
    fact(NewN, F1),
    F is F1*N.

fact(0, F) :- F is 1.
```

### Características da recursão em Prolog

- **Cada nível de recursão** tem seu próprio conjunto de variáveis.
- A **unificação** entre o objetivo e o padrão de uma regra recursiva define as relações
  entre as variáveis de diferentes níveis.
- É preciso garantir que os **parâmetros não caracterizem uma cláusula-base**. Sem esse
  cuidado, um retorno pela porta `redo` em alguma subconsulta pode fazer um conjunto de
  valores que caracterizava uma cláusula-base **avançar na regra recursiva**, causando
  erros como **laços infinitos**.

## 3. Exemplos de recursão

### Fibonacci (iterativo via acumuladores — recursão de cauda)

```prolog
fibTR(N, B, A, F) :-
    N > 0,
    succ(NewN, N),
    C is A + B,
    fibTR(NewN, C, B, F).

fibTR(0, _, Acc, Acc).

:- use_module(library(arithmetic)).
:- arithmetic_function(fib/1).

fib(N, F) :- fibTR(N, 1, 0, F).

?- X is fib(200).
X = 280571172992510140037611932413038677189525.
```

### Recursão simples × recursão de cauda

Considere o fatorial. A versão **não-cauda** (`fact/2`) faz o cálculo **depois** da chamada
recursiva (`F is F1*N`), acumulando chamadas pendentes na pilha. A versão **de cauda**
(`factTR/3`) passa o resultado acumulado (`NewAcc`) para a próxima chamada:

```prolog
% recursão comum
fact(N, F) :- N > 0, succ(NewN, N), fact(NewN, F1), F is F1*N.
fact(0, F) :- F is 1.

% recursão de cauda (otimizada)
factTR(N, Acc, F) :-
    N > 0,
    succ(NewN, N),
    NewAcc is Acc * N,
    factTR(NewN, NewAcc, F).
factTR(0, Acc, F) :- F is Acc.

factorial(N, F) :- factTR(N, 1, F).
```

**Diferença-chave:**

| Recursão comum | Recursão de cauda |
|---|---|
| O resultado depende da chamada recursiva (`F is F1*N`) | O resultado já vem acumulado na chamada |
| Acumula chamadas pendentes na pilha | Pode ser otimizada (a pilha não cresce) |
| Sufoca a pilha em entradas grandes | Suporta entradas muito grandes |

> Comparando com Python (iterativo): o mesmo Fibonacci iterativo leva ~9,25s para $10^6$;
> em Prolog (recursão de cauda), ~6,49s.

## 4. Estruturas de dados em Prolog

Uma **estrutura de dados** combina termos primitivos (átomos, inteiros) e estruturas em
**tipos compostos**. A sintaxe de declaração é idêntica a um fato:

```prolog
functor(arg1, arg2, ..., argN).
```

- Cada argumento pode ser um tipo primitivo ou **outra estrutura** (aninhamento).
- A declaração de uma estrutura é **semelhante à declaração de um fato**.

```prolog
car(peugeot, black, 2).
car(honda, red, 4).
```

### Consultas envolvendo estruturas

- A **ordem dos argumentos** influencia o resultado de uma consulta.

```prolog
car(X, red, _).        % que carro é vermelho com 4 portas?
```

- Campos podem ser ignorados com a variável anônima `_`.
- Estruturas podem ser **aninhadas** para legibilidade:

```prolog
car(honda, color(red), doors(4)).
```

> As cláusulas `car(honda, red, 4)` e `car(honda, color(red), doors(4))` **não unificam**:
> os argumentos são estruturas diferentes (`red` ≠ `color(red)`).

### Exemplo — matrioskas (estrutura + recursão)

```prolog
matrioska(a, b).
matrioska(a, c).
matrioska(b, d).
matrioska(b, c).
matrioska(b, f).
matrioska(c, e).
matrioska(c, g).
matrioska(d, g).
matrioska(e, f).
matrioska(f, g).
matrioska(f, h).

% Função recursiva auxiliar: imprime as matrioskas aninhadas
list_(M, L) :-
    nl,
    tab(L),
    print(->),
    tab(1),
    print(M),
    matrioska(M, X),
    NewL is L + 4,
    list_(X, NewL).

list(M, L) :- list_(M, L).
list(_, _).

doll(X) :- matrioska(X, _).
doll(X) :- matrioska(_, X).
```
