# 02.0 - Guia de instalação: SWI-Prolog no Windows

> O curso usa **SWI-Prolog** (o comando `sudo apt-get install swi-prolog` dos slides é
> para Linux). No Windows o interpretador é o mesmo, mas o executável se chama **`swipl`**
> (e não `prolog` como no Linux).

---

## Opção 1 (recomendada): via winget

Abra o **PowerShell** ou **Prompt de Comando** e execute:

```powershell
winget install -e --id SWI-Prolog.SWI-Prolog
```

Aguarde o download e a instalação terminar. É a versão estável mais recente (10.0.x).

## Opção 2: instalador manual

1. Acesse https://www.swi-prolog.org/download/stable
2. Baixe o arquivo `swi-prolog-<versão>-x64.exe` (Windows 64 bits, ex.: `SWI-Prolog 10.0.2-1`)
3. Execute o instalador e avance com *Next* até concluir (a opção de adicionar ao **PATH**
   vem marcada por padrão — mantenha marcada).
4. Instala dois executáveis: `swipl.exe` (console) e `swipl-win.exe` (janela gráfica).

## Opção 3: WSL (ambiente igual ao do curso)

Se quiser exatamente o ambiente dos slides (comando `prolog` e `apt-get`):

```bash
wsl --install                     # instala o Ubuntu no Windows
sudo apt-get update
sudo apt-get install swi-prolog
```

---

## Verificando a instalação

1. **Abra um novo terminal** (para pegar o PATH) e digite:

```powershell
swipl
```

2. Deve aparecer o *listener* do Prolog com o prompt `?-`:

```
Welcome to SWI-Prolog (threaded, 64 bits, version 10.0.2)
...
?- 
```

3. Teste os exemplos da aula 01:

```prolog
?- true.
true.

?- false.
false.

?- writeln('Hello').
Hello
true.
```

4. Para sair:

```prolog
?- halt.
```

---

## Carregando arquivos `.pl` (fatos do curso)

Os fatos das aulas ficam em arquivos `.pl`. Para carregar:

**Na inicialização:**
```powershell
swipl -s codes/conectivos.pl
```

**Em uma sessão interativa** (equivalente ao `consult/1` dos slides):
```prolog
?- consult('codes/conectivos.pl').
true.

?- and(true, false).
false.
```

---

## Diferenças entre Windows e os slides

| Slides (Linux) | Windows |
|---|---|
| `$ prolog` | `swipl` |
| `$ prolog -s source.pl` | `swipl -s source.pl` |
| `consult/1` e `reconsult/1` | iguais |
| `sudo apt-get install swi-prolog` | winget ou instalador `.exe` |

**Referência:** https://www.swi-prolog.org/ (site oficial, acesso em 2026).
