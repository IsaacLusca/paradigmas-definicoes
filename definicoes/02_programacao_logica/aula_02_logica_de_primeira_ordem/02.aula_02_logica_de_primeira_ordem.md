## 1. Contexto / Motivação

A lógica proposicional (aula 01) trata de proposições **atômicas** — frases completas que são
verdadeiras ou falsas. Mas a matemática e a programação precisam de algo mais: expressar
**generalizações** como "todo estudante da UnB..." ou "existe um X tal que...". Para isso,
a lógica de primeira ordem introduz **variáveis**, **quantificadores** e **sentenças abertas**
(funções proposicionais). Em Prolog, essas ideias viram **regras** e **consultas** — o
vocabulário que permite escrever programas de verdade.

---

## 2. Variáveis e constantes

- Uma **variável** é um símbolo que representa um objeto **não especificado** de um
  determinado conjunto $U$, chamado **conjunto universal** da variável.
- Uma **constante** é um **membro específico** do conjunto universal.

> Ex.: em `paciente('Carlos', 38)`, `'Carlos'` e `38` são **constantes**. Já uma consulta
> `paciente(X, Idade)` tem `X` e `Idade` como **variáveis** (objetos a descobrir).

---

## 3. Termos em Prolog

Prolog tem um **único tipo de dado**, chamado **termo**. Todos os argumentos de predicados
são termos. Os termos podem ser:

- **Átomos** — nomes de propósito geral, iniciados com **letra minúscula** (ex.: `dolar`,
  `eixo_x`). Para usar maiúsculas ou espaços, delimite com **aspas simples**: `'Pedro Lucas'`.
- **Números** (inteiros ou flutuantes) — termos primitivos.
- **Variáveis** — subtipo de termo, iniciadas com **maiúscula** ou `_`.

```prolog
% Valores em 10/03/2026
cotacao(dolar, 5.16).
cotacao(euro, 6.01).
cotacao(iene, 0.03).

% O primeiro argumento é o nome, o segundo a idade
paciente('Carlos', 38).
paciente('Maria', 26).
paciente('Pedro Lucas', 40).

% Átomos podem conter underscore e números
limites(eixo_x, -10, 10).
```

## 4. Sentenças abertas

Uma **sentença aberta** $S(x)$ em $x$ é uma expressão em que o símbolo $x$ ocorre uma ou
mais vezes e que, **se todas as ocorrências de $x$ forem substituídas por uma constante**
$v$ do conjunto universal de $x$, $S(v)$ torna-se uma **proposição** (passível de V/F).
Sentenças abertas também são chamadas **predicados** ou **funções proposicionais**.

> Ex.: $S(x)$ = "x é estudante da FCTE". Substituindo `x = ana`, temos a proposição
> "ana é estudante da FCTE" — verdadeira. Com `x = diana`, falsa.

---

## 5. Variáveis e regras em Prolog

As variáveis permitem declarar **sentenças abertas** em Prolog, chamadas **regras**.
Sintaxe da regra `rule/N`:

```prolog
rule(X1, X2, ..., XN) :- body.
```

| Parte | Significado |
|---|---|
| `rule` | **nome** do predicado |
| `X1..XN` | **argumentos** |
| `N` | **aridade** |
| `body` | **corpo** (proposição composta) |
| `.` | **terminador** |

### Declarando regras

- Regras devem estar em arquivo `.pl`.
- O corpo deve ser uma **proposição composta** ou ser **omitido**.
- **Regras sem corpo = fatos** (são equivalentes):

```prolog
f(1).
f(1) :- true.
```

- Podem existir **múltiplas regras** para o mesmo predicado — o predicado é a **disjunção**
  (ou) de todas as regras e fatos declarados:

```prolog
fcte(ana).
fcte(beto).
fcte(carlos).
darcy(diana).
darcy(esther).
ifb(fernando).

unb(X) :- (fcte(X) ; darcy(X)).

unb2(X) :- fcte(X).
unb2(X) :- darcy(X).
```

- Em Prolog, **fatos e regras são denominados cláusulas**.

## 6. Quantificador existencial

Seja $S(x)$ uma sentença aberta. O **quantificador existencial** $\exists$ é usado em
$\exists x.S(x)$, que significa: **existe pelo menos um** elemento $v$ no conjunto universal
de $x$ tal que $S(v)$ é verdadeira.

Em Prolog, o quantificador existencial está associado às **consultas**:

- Uma **consulta simples** é uma sentença aberta simples (predicado + argumentos).
- Se um ou mais argumentos são substituídos por uma **variável lógica** e a consulta for
  verdadeira, o interpretador indica as **atribuições** que a tornaram verdadeira.
- Se houver **duas ou mais** atribuições, digite `;` (ponto-e-vírgula) no interpretador
  para obter as demais.

```prolog
?- unb(fernando).
false.

?- unb(diana).
true.

?- ifb(X).
X = fernando.

?- unb(X).
X = ana ;
X = beto ;
X = carlos ;
X = diana ;
X = esther.
```

### Consultas e variáveis lógicas

- As consultas são avaliadas por **unificação** (casamento de padrões).
- O padrão de uma consulta é chamado **objetivo** (*goal*).
- **Variáveis lógicas não se comportam como as de outras linguagens**: durante a
  unificação, uma variável **casa com qualquer termo**; após unificar, a variável fica
  **atada** (*to bind*) ao termo que casou.

---

## 7. Unificação (versão simplificada)

Se a base Prolog contém apenas **fatos**, a unificação é bem-sucedida se as três condições
abaixo forem satisfeitas:

1. O **predicado** do objetivo e da base é o **mesmo**;
2. Ambos têm a **mesma aridade**;
3. **Todos os argumentos são os mesmos**.

```prolog
f(1, 2).
f(1, 3).
f(2, 3).
g(1).
g(2).

?- f(1, 2).
true.

?- f(2, 1).
false.

?- f(1).
false.        % aridade diferente

?- g(1, 2).
false.
```

**Mesma variável lógica** em dois argumentos força que eles tenham o mesmo valor:

```prolog
f(1, 1). f(1, 2). f(1, 3).
f(2, 1). f(2, 2). f(2, 3).
g(a, 1). g(1, a).

?- f(X, X).
X = 1 ; X = 2 ;
false.

?- g(X, X).
false.
```

## 8. Fatos dinâmicos

Prolog permite **declarar ou retratar fatos diretamente no interpretador**:

- O predicado deve ser declarado **dinâmico** com a diretiva `dynamic` (nome + aridade),
  **só em arquivo**.
- `asserta/1` adiciona um fato no **início** da base; `assertz/1` adiciona no **fim**.
- `retract/1` **apaga** um fato da base.

```prolog
:- dynamic
    coordenador/1.

coordenador(matheus).       % CNA
coordenador(himilsys).      % Automotiva
coordenador(batistuta).     % Eletrônica
coordenador(sebastien).     % Aeroespacial

?- asserta(coordenador(andrea)).   % Energia
true.

?- assertz(coordenador(john)).     % Software
true.

?- retract(coordenador(matheus)).
true.

?- coordenador(X).
X = andrea ;
X = himilsys ;
X = batistuta ;
X = sebastien ;
X = john.
```

## 9. Quantificador universal e generalizações

O **quantificador universal** $\forall x.S(x)$ significa que **para todos** os valores $v$
no conjunto universal de $x$, $S(v)$ é verdadeira.

Em Prolog, o $\forall$ é expresso por uma **generalização** — um **fato que casa com
qualquer valor**:

```prolog
is_term(_).
```

- `is_term(_)` é verdadeiro para qualquer argumento (um argumento de predicado sempre é
  um termo).
- Como a variável não é usada no corpo, usa-se o **wildcard** `_` em vez de uma variável
  nomeada.

```prolog
?- is_term(1).     % Números são termos
true.
?- is_term(abc).   % Átomos são termos
true.
?- is_term(A).     % Variáveis são termos
true.
?- is_term(A, B).  % erro: is_term tem aridade 1
```
